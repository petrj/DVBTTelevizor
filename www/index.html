DVBT Televizor

DVBT/FM/DAB player for Android

Software Requirements

  • DVB-T Driver from Google Play
  • RTL SDR driver from Google Play

Hardware Requirements

  • Compatible TV USB DVBT/DVBT2/RTL SDR tuner for Android
View Project on GitHub

Key Features

  • Free, no ads
  • DVBT/DVBT2
  • FM mono/stereo
  • DAB/DAB+
  • Works completely offline (no internet connection required)
  • Supports external keyboards and remote controls mapped as keyboards (USB, Bluetooth)
  • Recording capabilities to internal and external storage
  • Automatic and manual tuning
  • Export and import tuned channel configurations
  • Electronic DVBT Program Guide (EPG) showing current and next schedules
  • Option to enlarge font sizes (ideal for tablets and Android TVs)
  • Android 5.0 and higher supported on multiple architectures: armeabi, armeabi-v7a, x86, x86_64, arm64-v8a
  • Audio tracks switching
  • DVB subtitles support
  • Teletext support
  • Remote access from other devices via Remote Televizor
    • Get Remote Televizor on Google Play
    • Windows x64 / Universal Android apk
